# Content review checklist

Use this checklist when updating the academic website:

- Explain research questions, methods and findings through verified publications. Distinguish modelled results from observations and retain the relevant scenario scope.
- Keep roles, qualifications, project participation and publication status accurate. Research centres first-author work and clearly credits collaborations.
- Keep Home concise; use Research for explanations, Publications for the bibliography and Projects for short funded-project entries.
- Preserve figure attribution and version-specific licences in both the page and `content-sources.md`.
- Review responsive layouts, keyboard navigation, meaningful link labels, image alt text and working redirects.
- Check semantic metadata, canonical URLs, sitemap and crawler settings without promising search indexing or ranking.
- Treat every tracked file as public, including comments and Markdown documentation. Keep detailed private reviews, source documents and unpublished material in ignored local storage.

Run the checks in `validation.md` before publication. Detailed working notes are not part of the public repository.
